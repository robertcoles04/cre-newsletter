# CRE Blurb Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish approved issues to a static GitHub Pages site when Robert adds the `approved` label to a draft Issue.

**Architecture:** Delivery also saves the fact sheet as `issues/<date>.json`. A gate (`src/publish.py`) checks the edited md and records the date in `issues/published.json`. A builder (`src/site.py`) rebuilds every page from the published list using the existing `render_issue_html`, and `publish.yml` deploys it with the official Pages actions.

**Tech Stack:** Python 3.11+, `markdown`, pytest, GitHub Actions (`actions/upload-pages-artifact@v3`, `actions/deploy-pages@v4`), `gh` CLI.

**Spec:** `docs/superpowers/specs/2026-10-05-website-design.md`

## Global Constraints

- Site URL constant: `SITE_URL = "https://robertcoles04.github.io/cre-newsletter/"` (one place, in `src/site.py`).
- Design: Offering Memo per `DESIGN.md` (navy `#0E2A47`, gold `#B08D3C`, Libre Caslon Text + Public Sans). No JavaScript, no new colors, no emoji.
- The model never writes numbers: the Market Summary on the site is rebuilt from `issues/<date>.json` `values`.
- Blockers (refuse to publish): `[CHECK]` (case-insensitive), `{{`, the heading `# Claude unavailable: fact sheet only`.
- Banner to strip: the blockquote starting `> **Review before publishing:**` and every consecutive `>` line after it.
- Live pages never show the editor-notes box (`problems=[]`).
- About-page disclaimer and footer: `For informational purposes only. Not investment advice.` (the existing `FOOTER`).
- Data sources named on About: FRED, U.S. Treasury, Polymarket, Alpha Vantage.
- `site/` is build output: gitignored, never committed.
- Tests: `.venv/Scripts/python -m pytest -q` (151 passing before this plan). Bash, not PowerShell.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Edits made on github.com come back with CRLF line endings.** The banner strip and blockers must still work on `\r\n` text (tests in Task 3).
2. **The date reaches the filesystem from an Issue title.** Anything other than a real `YYYY-MM-DD` must be rejected before building any path (`publish` exits 2; test in Task 3; workflow regex in Task 5).
3. **Approving an older date after a newer one.** Home must show the newest *date*, not the most recently approved one (test in Task 4).
4. **Approving the same date twice** (label removed and re-added): `published.json` stays deduplicated and the site rebuilds cleanly (tests in Tasks 3 and 4).
5. **A missing chart PNG.** The page renders without an `<img>` and without `og:image`, with no crash (test in Task 4).

### Task 4: Site builder (`src/site.py`)

**Files:**
- Create: `src/site.py`
- Modify: `.gitignore` (add `site/`)

**Interfaces:**
- Consumes: `render_issue_html(..., head_extra=, nav=, extra_body=, title=)` and `render_page` (Task 2); `load_published`, `strip_banner` (Task 3); `FOOTER` from `src.checks`.
- Produces:
  - `SITE_URL = "https://robertcoles04.github.io/cre-newsletter/"`
  - `describe(md: str, day: date) -> str`: from the first `## ` section whose heading is not `The Numbers`, take the first prose line (skip headings, `-`/`*`/digit list items, `>`, images, blank lines). Reduce links `[t](u)` to `t`, drop `*`/`_` emphasis, take the first sentence (up to and including the first `. `, `! ` or `? `). Trim to 155 chars on a word boundary, adding `…` if trimmed. Fallback: `f"Daily commercial real estate briefing for {day:%B} {day.day}, {day.year}."`
  - `build(root: Path, out: Path, site_url: str = SITE_URL) -> list[str]`: deletes and recreates `out`, writes every page, returns published dates newest first. Dates in `published.json` whose md/json are missing are skipped with a printed warning.
  - `main(argv=None) -> int`: `python -m src.site build [--root .] [--out site]`.
- Page rules:
  - **Relative links by depth:** root pages use prefix `""`, `archive/` and `about/` use `"../"`, `issues/D/` uses `"../../"`. `404.html` uses absolute `site_url` links because it is served at any path.
  - **Nav:** `<nav class="site-nav" aria-label="Site"><a href="{p}">Home</a><a href="{p}archive/">Archive</a><a href="{p}about/">About</a></nav>`, styled by a `SITE_CSS` `<style>` block passed inside `head_extra` (navy links, small, padded like `main`, hairline bottom border).
  - **Head:** description, `<link rel="canonical">`, `og:title`, `og:description`, `og:url`, `og:type` (`article` for issues, `website` otherwise), `og:site_name` = `CRE Blurb`, `twitter:card` (`summary_large_image` with an image, else `summary`), and `og:image` = `{site_url}issues/D/chart.png` only when the PNG was copied. All attribute values HTML-escaped.
  - **Issue page:** `render_issue_html(strip_banner(md), factsheet_json, [], "chart.png" or None)`; chart copied from `issues/img/<D>-chart.png`.
  - **Home:** the newest-dated issue in full (head points canonical/og at that issue's URL), with `extra_body` = `<section><h2>Recent issues</h2><ul>…</ul></section>` linking the 10 newest (`Monday, October 5, 2026`). With zero issues: a `render_page` saying the first issue is coming soon.
  - **Archive:** `<h2>` per month (`October 2026`), newest first, with a list of links.
  - **About:** a short paragraph on what CRE Blurb is (a free daily commercial real estate briefing; a pipeline gathers news and market data each morning and drafts the issue; Robert reviews every issue before it is published), a list of the data sources (linked: fred.stlouisfed.org, home.treasury.gov, polymarket.com, alphavantage.co) plus "news outlets linked in each story", and `FOOTER`.
  - **404:** "Page not found" plus links Home and Archive.
